📅 월별 계획 (TV 하단 공고)

입력한 달의 계획이 화면 하단에 흘러가는 공고로 표시되고, 📢 공고 버튼(또는 설정의 자동 공고)으로 전체 화면에 크게 띄울 수 있습니다.

⚙ 설정

이상이면 붉게 표시 (기본 10)
시간당 강수량 기준 (기본 5)
15초 동안 표시
서버 없이 쓸 때 전체 초기화 보호

인원(식수) 계산 규칙 : 직영 인원 합계 + 직영 장비 수량(대당 기사 1명) + 날짜별 조정값.
편집 모드에서 장비·인원 행의 「직영」을 체크하면 화면에 밑줄로 표시되고 인원 집계에 포함됩니다.

💾 백업 / 복원

모든 입력은 이 브라우저에 자동 저장되며, 1시간마다 자동 백업본(최근 20개)이 따로 쌓입니다. 다른 PC·TV로 옮기거나 안전하게 보관하려면 파일로 내보내세요.

    📤 현장에 보내기 (카카오톡)

    현장을 고르거나 새로 만든 뒤 「카카오톡으로 보내기」를 누르세요. 가입 신청은 본사 관리자가 승인합니다. 받은 사람이 링크를 열면 그 현장으로 바로 회원가입·로그인 화면이 열리고, 승인하면 그 현장 자료만 보고 입력합니다.

    ✔ 문구와 링크를 복사했습니다.
    ① PC 카카오톡을 열고 ② 보낼 대화방(현장 단톡방)을 연 뒤 ③ 입력칸에 Ctrl+V → Enter
    휴대폰에서 이 버튼을 누르면 공유 창에서 카카오톡을 바로 고를 수 있습니다.
    카카오 JavaScript 키 🔒 (선택 — PC에서도 카톡 창이 바로 열리게)

    키가 없어도 휴대폰에서는 공유 창에서 카카오톡을 고르면 바로 보내집니다. PC에서는 문구와 링크가 복사되니 카톡 PC에 붙여넣으면 됩니다.
